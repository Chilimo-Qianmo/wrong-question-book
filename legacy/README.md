# 旧版（v1）备份

这里的文件是 v2 之前的实现，**仅为回退与对照保留**，新功能不会再更新。

| 文件 | 说明 |
|---|---|
| `生成错题集.py` | 旧核心（1383 行）：OCR、Word 生成、归档、合并 |
| `错题集生成器.py` | 旧 tkinter 图形界面（958 行） |
| `错题集生成器.spec` | 旧版 PyInstaller 打包脚本 |
| `一键启动-旧版.bat` | 旧版启动脚本 |
| `打包exe-旧版.bat` | 旧版打包脚本 |

## 使用旧版
```
cd legacy
python 错题集生成器.py          # 需要 customtkinter（pip install customtkinter）
```
旧版会把 `错题集`、`题目配置`、`图片` 建在 `legacy/` 目录下（因为它按脚本所在目录定位），
不会与 v2 的数据混在一起。

## 为什么退役
v2 用「双通道 PDF 解析（电子版走文字层 / 扫描版走 OCR）+ 行聚类归题 + 缺口告警」重写了识别引擎，
并修复了旧版一批已实测复现的缺陷（详见上级目录 `使用说明.md` 第三节）。
旧版界面是单窗口 tkinter，无法承载「来源标注 / 置信度 / 缺口告警 / 图文预览 / 实时进度」这些新交互。
